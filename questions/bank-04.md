# 第4课 题库（技能）

## 单选题

**Q1.** 关于技能的定义，下列哪项最准确？
- A. 技能是 AI 模型训练时就内置的对话能力
- B. 技能是给 AI 配的工具装备，扩展 AI 的能力边界，让 AI 从「会说」变成「能做」
- C. 技能是连接外部邮箱、数据库等远程服务的协议
- D. 技能是用于管理任务和日程的助理配置模块

> **答案：B**｜**解析**：技能的本质是给 AI 配装备；A 是普通对话的能力来源，C 是 MCP 连接器，D 属于五大组件中的其他模块。｜**考点**：一、技能是什么

**Q2.** 技能的底层调用技术叫什么？
- A. OAuth 授权
- B. RAG 检索增强
- C. Function Calling（工具调用）
- D. Prompt Chaining

> **答案：C**｜**解析**：技能的底层技术是 Function Calling；OAuth 是 MCP 连接器的主要接入方式。｜**考点**：二、Function Calling 机制

**Q3.** 在 Function Calling 流程中，「帮我把桌面的 report.docx 转成 PDF」这句话里，file_path 和 target_format 参数是如何确定的？
- A. 用户必须先手动填写参数表单
- B. AI 从对话上下文中自动推理提取
- C. 系统从配置文件中读取默认值
- D. 技能安装时就已固定写死

> **答案：B**｜**解析**：参数推理是 Function Calling 三大特征之一，AI 自动从对话上下文提取参数，用户只需说话。｜**考点**：二、Function Calling 机制

**Q4.** 关于技能与 MCP 的执行环境，下列说法正确的是？
- A. 技能通过网络调用远程服务，MCP 在本机运行
- B. 两者都在本机运行
- C. 技能在本机运行、使用本机 CPU 和内存，MCP 通过网络调用远程服务
- D. 两者都通过 OAuth 授权后在云端执行

> **答案：C**｜**解析**：执行环境是技能与 MCP 的核心区别之一，方向不能搞反。｜**考点**：三、技能与 MCP 的关系

**Q5.** 「数据在外面，用连接器；处理在本地，用技能」体现的是哪方面的内容？
- A. 安全沙箱机制
- B. 技能与 MCP 的选择原则
- C. 最佳实践的单一职责原则
- D. 插件与技能的打包关系

> **答案：B**｜**解析**：这是技能与 MCP 的选择原则；复杂任务则两者一起用。｜**考点**：三、技能与 MCP 的关系

**Q6.** 下列哪项不属于 WorkBuddy 安全沙箱的机制？
- A. 工作目录隔离
- B. 危险操作弹窗确认
- C. 技能调用审计日志
- D. 技能必须经过用户所在单位 IT 部门审批才能安装

> **答案：D**｜**解析**：安全沙箱六层机制为目录隔离、危险确认、权限按需、用户可控、来源审核、审计日志，不含单位 IT 审批。｜**考点**：四、安全沙箱

**Q7.** 上传本地技能包时，技能包中必须包含哪个文件？
- A. config.json，用 JSON 声明技能参数
- B. skill.md，用 YAML 格式声明技能的名称和描述
- C. readme.txt，用纯文本说明用法
- D. manifest.xml，用 XML 声明技能版本

> **答案：B**｜**解析**：课程明确技能包必须包含 skill.md，且用 YAML 格式声明名称和描述。｜**考点**：六、三种安装方式

**Q8.** 三种安装方式中，课程最推荐普通用户使用哪一种？
- A. 上传本地技能包
- B. 查找技能（用自然语言描述需求，AI 自动匹配安装）
- C. 创建技能（AI 从零生成）
- D. 命令行安装

> **答案：B**｜**解析**：查找是最推荐的方式，描述需求即可；上传适合已有技能包，创建适合库里没有的情况。｜**考点**：六、三种安装方式

**Q9.** 使用「创建技能」方式时，WorkBuddy 收到需求后的第一步动作是？
- A. 直接生成技能并自动安装
- B. 先弹出付费确认窗口
- C. 反过来向用户提几个关键问题，对齐需求
- D. 先在技能市场中搜索同名技能

> **答案：C**｜**解析**：创建技能时 AI 不会闷头生成，而是先反问关键问题（处理类型、输出格式、典型场景），确保生成物真的能用。｜**考点**：六、三种安装方式

**Q10.** 下列哪个技能的核心能力是「技能安全检测」，被称为「技能杀毒软件」？
- A. Find Skills
- B. Self Improvement
- C. Skill Scanner
- D. Agent Browser

> **答案：C**｜**解析**：Skill Scanner 用于新装技能时做安全审计；Find Skills 是按需求找技能，注意区分。｜**考点**：八、十大内置技能

**Q11.** 会议录音需要转成文字纪要，且内容涉密不能联网，应优先使用哪个内置技能？
- A. Web Search
- B. Local Whisper
- C. YT-DLP Downloader
- D. Obsidian

> **答案：B**｜**解析**：Local Whisper 本地语音转文字、不需联网、隐私优先，正合此场景。｜**考点**：八、十大内置技能

**Q12.** Web Search 技能主要解决什么问题？
- A. 本地文件无法批量处理
- B. 大模型知识有截止日期，无法获取最新信息
- C. 浏览器操作无法自动化
- D. 笔记库无法被 AI 读取

> **答案：B**｜**解析**：Web Search 联网搜索实时信息，弥补大模型知识截止的短板，避免编造答案。｜**考点**：八、十大内置技能

## 多选题

**Q13.** 技能与普通对话的区别体现在哪些维度？（ ）
- A. 能力来源
- B. 一致性
- C. 可重复性
- D. 适用场景

> **答案：ABCD**｜**解析**：课程从能力来源、一致性、可重复性、适用场景四个维度对比，核心区别是「说」与「做」。｜**考点**：一、技能是什么

**Q14.** 安装技能有哪几种方式？（ ）
- A. 上传本地技能包（ZIP 或文件夹）
- B. 查找技能（AI 在技能库搜索匹配）
- C. 创建技能（AI 从零生成专属技能）
- D. 通过 OAuth 授权接入

> **答案：ABC**｜**解析**：三种安装方式为上传、查找、创建；OAuth 授权是 MCP 连接器的接入方式，是常见干扰项。｜**考点**：六、三种安装方式

**Q15.** 关于「启用过多技能」的副作用，课程提到了哪些？（ ）
- A. AI 可能误调用不相关的技能
- B. 上下文膨胀导致推理变慢
- C. 匹配精度下降
- D. 已安装技能会被自动卸载

> **答案：ABC**｜**解析**：三个副作用为误调用、上下文膨胀、匹配精度下降；启用多少与自动卸载无关。｜**考点**：九、最佳实践

**Q16.** 下列关于办公文档四件套能力的描述，正确的有？（ ）
- A. PDF 技能可识别表格数据并转成 Excel、支持扫描件 OCR
- B. DOCX 技能可自动生成目录、处理批注和修订
- C. PPTX 技能可把十页 PPT 压缩成三页、按大纲重新制作演示文稿
- D. XLSX 技能可自动补公式、清洗脏数据、多表合并

> **答案：ABCD**｜**解析**：四项均为四件套的原文能力点，四件套是考试必考重点。｜**考点**：八、十大内置技能·四件套明细

## 判断题

**Q17.** 插件是技能的打包组合，一个插件可以包含多个技能。（ ）
> **答案：正确**｜**解析**：概念速记第四点原文，方向不要记反（不是技能包含插件）。｜**考点**：一、概念速记

**Q18.** 关闭技能后，该技能的文件会被系统删除，再次使用需要重新安装。（ ）
> **答案：错误**｜**解析**：关闭不等于删除，文件仍保留，打开开关即可零成本恢复；卸载才是彻底删除。｜**考点**：七、四大日常管理操作

**Q19.** 技能是在本机运行的，而 MCP 连接器主要通过 OAuth 授权接入、通过网络调用远程服务。（ ）
> **答案：正确**｜**解析**：这是技能与 MCP 在执行环境和安装方式上的双重区别。｜**考点**：三、技能与 MCP 的关系

**Q20.** 为了安全起见，技能市场上的技能可直接上架，无需平台审核。（ ）
> **答案：错误**｜**解析**：来源审核是安全沙箱六层机制之一，市场技能必须经平台审核才能上架。｜**考点**：四、安全沙箱

## 场景应用题

**Q21.** 小王本周的主要工作是数据分析：需要把 50 份 PDF 财务报表里的表格提取到 Excel，汇总成一张报表，并把每天的会议录音整理成文字纪要（内容涉密）。下周他要转做宣传物料设计。请说明：（1）他本周应启用哪些技能？（2）技能开关下周应如何调整，为什么？

> **参考答案**：（1）本周启用办公文档四件套中的 PDF 技能（识别表格转 Excel）和 XLSX 技能（清洗、合并、生成汇总报表），加 Local Whisper（本地语音转文字、不联网、隐私优先）处理涉密录音；启用数量控制在 3-5 个。（2）下周转做设计时，关闭 PDF/XLSX/Whisper，开启海报设计类技能（如 Frontend Design）——这体现「按场景切换」最佳实践：关闭不等于删除、切换零成本，且启用技能越少，AI 从已启用技能中匹配的准确率越高，避免误调用、上下文膨胀和精度下降。
> **解析**：综合考查十大内置技能选型 + 最佳实践的「仅启用所需、按场景切换」。｜**考点**：七、四大管理操作；八、十大内置技能；九、最佳实践

**Q22.** 小李想批量处理 PDF 提取表格数据，但不知道技能市场里有没有现成技能。他先用了「查找技能」，AI 搜索后发现技能库里没有完全匹配的技能。请问他接下来应该怎么做？整个过程中 AI 会有哪些关键动作？

> **参考答案**：接下来使用「创建技能」：在技能市场右上角「添加技能」中选择创建，用一句话描述需求（如「请帮我创建一个可以批量处理 PDF 提取表格数据的技能」）。AI 的关键动作：先反问几个关键问题对齐需求（处理什么类型的 PDF 表格、希望输出什么格式、典型批量场景是什么）→ 生成详细的技能功能清单和结构说明供小李确认 → 确认后自动安装到已安装列表 → 在对话框中直接引用即可使用。这体现 WorkBuddy 的自我进化能力：你缺什么，AI 就帮你长什么。
> **解析**：考查三种安装方式的适用顺序（有现成→上传/查找，没有→创建）与创建流程的完整步骤。｜**考点**：六、三种安装方式
