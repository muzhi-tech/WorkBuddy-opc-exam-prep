# 第6课 考点笔记：灵感模块

## 一、灵感模块定义

- 一句话定位：**灵感 = 社区智慧 + 一键复刻**，告别「空白页焦虑」（新手面对空白对话框不知说什么）。
- 本质：WorkBuddy **社区精选的成品作品集**。不是工具箱，不是 AI 顾问，是别人已经做好的作品展示间。
- 配方构成：每个灵感模板 = **Prompt + 技能 + 专家配置**的最优组合，由高手预先调优。
- 五个问答速记：
  - 谁做的？WorkBuddy 社区用户贡献的精选成品集。
  - 看什么？已打磨好的真实作品案例（不是半成品）。
  - 怎么做？点「做同款」，一键复刻。
  - 得到啥？提示词、技能、专家配置全部自动就位。
  - 省在哪？省从零设计的时间 + 省反复试错的 token。
- 四个关键词：**定位**（社区精选成品集、新手最佳起点）；**形式**（完整作品，含提示词+技能+专家配置）；**动作**（点「做同款」）；**效果**（零配置直接生成专属版本）。
- 类比：菜谱杂志——每道菜是大厨做好的成品，按配方做即可，无需从零研发。

## 二、提示词工程基础

- 提示词：发给 AI 的指令文本，直接决定 AI 输出质量。
- 好用提示词的 **4 个关键要素**：
  1. **角色设定**：告诉 AI「你是某某专家」，进入特定领域思维（如「你是资深项目经理」）。
  2. **结构化指令**：拆清背景、任务、输出格式、约束条件，不让 AI 猜。
  3. **少样本示例**：给 1~3 个输入到输出的例子，让 AI 明白期望格式。
  4. **灵感模板封装**（最关键）：模板 = 完整最优配方，角色/提示词/技能/专家已全部调好。
- 结论：「做同款」的本质 = 复制别人调优好的提示词配方；用户不需成为提示词专家，只需会选模板。

## 三、「做同款」背后的五步处理链路

1. **输入层**：用户输入的文字 + 上下文（之前的对话、上传的文件）。
2. **提示词组装**：WorkBuddy 在后台把用户输入、系统提示、已启用技能描述、已连接外部工具能力组装成完整指令包。**灵感模板的价值就在这一步——预设了最优组装方式**。
3. **模型推理**：大模型判断直接回复还是调用工具。
4. **工具调用**：需要外部数据或操作时，触发对应技能或连接器执行。
5. **结果整合**：工具返回结果后，模型组织成最终回复。
- 核心记忆点：**灵感模板帮你把第二步（提示词组装）做到最优**。

## 四、灵感模块四大优势

1. **使用场景全覆盖**：覆盖日常与工作高频需求——写作、分析、总结、翻译、设计、编程、创意等，按需挑选，无需从零定义。
2. **一键复刻，零门槛**：系统自动预填 Prompt、加载关联技能、配置专家，三件事一次完成。
3. **节省 token，更高性价比**：精调案例减少冗余消耗，一次出好结果，避免多次试错。
4. **社区智慧持续沉淀**：复用高手经验，掌握场景化最佳实践，社区不断贡献新模板。

## 五、操作流程（四步：打开、选择、制作、查看）

### 第一步：打开灵感
- 入口：主页**左侧边栏点「更多」→ 展开菜单选「灵感」**。
- 页面两区域：上方场景分类标签（全部、精选、办公协作、投资理财、内容创作等）；下方灵感卡片，可按需筛选。

### 第二步：查看案例详情
- 点卡片弹出详情窗口，分左右两部分：
  - **左边预览区**：看模板实际产出效果（标题、副标题、内容模块）。
  - **右边详情面板**，三个关键信息：
    1. **标签类型**：如 HTML 页面、智能页面、数据看板，判断输出格式。
    2. **使用的工具集**：案例背后用了哪些技能或专家（如腾讯文档智能页面）。
    3. **详细介绍**：适合什么场景、解决什么问题。
- 可点预览区右上角**红心收藏**，下次从收藏夹直达；或直接点「做同款」。

### 第三步：一键复刻（做同款）
- 点「做同款」后系统自动做三件事：
  1. 提示词自动预填到输入框；
  2. 模板所需技能自动启用就位；
  3. 对应专家角色自动配置好。
- 用户只需**微调参数**（改主题、换对象）→ 点生成。全程零手写提示词、零技能配置。

### 第四步：查看和管理生成结果
- 三种方式：
  1. **右侧产物页面**：默认掌管产物，显示文件列表、预览缩略图、文件大小。
  2. **网页文件自动预览**：HTML 页面/数据看板类结果自动打开**内置浏览器**预览，无需外部浏览器。
  3. **文件下载与继续编辑**：满意可下载到本地；不满意在对话框继续调参重新生成。
- 数据安全：**整个过程在电脑本地完成，数据不离开设备**。
- 耗时：从打开灵感到拿到成品，通常 **1~2 分钟**。

## 六、灵感 VS 技能 VS 专家（高频考点）

- 做菜类比：厨具=技能，厨师=专家，菜单=灵感。
- 一句话区别：**技能是工具，专家是带经验的工具，灵感是用工具做出来的成品**。

| 维度 | 技能 | 专家 | 灵感 |
|------|------|------|------|
| 定位 | 能力/工具 | 能力+经验 | 成品/作品 |
| 回答的问题 | WorkBuddy 能做什么 | 用什么方法做 | 做出来是什么样 |
| 适用时机 | 需要某种工具能力时 | 需要某领域专业视角时 | 不知道从哪开始时 |
| 类比 | 厨具（刀、锅、灶） | 厨师方法论（川菜师傅、法餐大厨） | 餐厅菜单（看图点菜） |

- 四大选择场景：
  1. 有清晰任务、缺工具 → **找技能**（如用 PDF 技能抽取表格）。
  2. 有领域问题、缺方法 → **召唤专家**（如法律顾问审合同）。
  3. 对要做什么没头绪 → **打开灵感**（浏览找方向）。
  4. 想沉淀团队经验 → **把作品发布/收藏到灵感**，供团队复刻复用。
- 速查口诀：**想要能力选技能，想要建议选专家，想要成品选灵感**。

## 易混点速记

| 易混点 | 正确结论 |
|--------|----------|
| 灵感是工具箱/AI 顾问？ | 不是。灵感是社区精选的**成品作品集** |
| 灵感模板包含什么 | Prompt + 技能 + 专家配置（三件套最优配方） |
| 做同款后还要手写提示词？ | 不用。提示词自动预填，只需微调参数 |
| 灵感模板优化的是五步链路哪一步 | 第二步「提示词组装」，不是模型推理 |
| 好提示词四要素 | 角色设定、结构化指令、少样本示例、灵感模板封装 |
| 网页结果要手动开浏览器？ | 不用，WorkBuddy 内置浏览器自动预览 |
| 生成结果去哪找 | 右侧产物页面（文件列表、缩略图、大小） |
| 灵感入口 | 左侧边栏「更多」→「灵感」，不是主页直接入口 |
| 技能/专家/灵感速查 | 能力→技能；建议/方法→专家；成品→灵感 |
| 生成过程数据去向 | 全程本地完成，数据不离开设备 |
| 收藏案例的方式 | 预览区右上角点红心，收藏夹直达 |
