# 第10课 考点笔记（典型办公场景综合理解）

核心：**跟 WorkBuddy 说清楚你要什么，它就能帮你交付什么。** 四大场景覆盖日常办公 80% 高频产出。

## 一、文档生成与报告编写

四类高频文档：
1. **工作报告**：周报、月报、项目立项申请。
2. **技术文档**：API 文档、技术方案、操作手册。
3. **会议纪要**：基于录音、视频转写稿或草稿，自动提取**议题、结论、待办、责任人、截止时间**五项。
4. **模块化复用**：常用格式封装为 **Skill 模板**，保证团队格式一致。

单次 → 直接对话；高频复用 → Skill 模板。误区：AI 不能猜需求，描述越精确输出越好。

### 任务描述四要素（考试核心）
1. **描述目标**：做什么、给谁看、要什么效果。
2. **明确对象与语气**：管理层版与同事版语气详略不同。
3. **一次说清结构**：结构、页数、必含模块第一句讲清，事后补 = 推倒重做。
4. **多轮迭代修改**：追问即可，AI **增量修改**不重写。

## 二、数据分析与可视化

四步：**导入 → 分析 → 出图 → 解读**
1. **导入**：Excel/CSV 拖入对话框或告知路径。
2. **自动分析**：说清指标、维度、时间范围，AI 完成统计、清洗、分组、异常识别。
3. **可视化**：柱状图、折线图、饼图，可换类型、调配色。
4. **解读汇报**：自动撰写结论、趋势判断、行动建议。

### 数据隐私与脱敏（重点）
- 上传前**务必脱敏**：姓名、身份证号、手机号、银行卡号、企业机密数据，替换为匿名标识。
- WorkBuddy 是**云端 AI 工具**，隐私安全是使用底线；原则：**需要什么给什么，不该给的一条都不能给。**

## 三、PPT 与演示文稿生成

四步：
1. **从需求到大纲**：先描述**受众、场景、页数、风格**，确认大纲再排版，避免返工。
2. **自动生成**：基于确认大纲一键产出，可指定模板保品牌一致。
3. **迭代美化**：逐页提修改，增量修改不整份重做。
4. **演示辅助**：一并生成演讲稿、备注、Q&A 答辩要点。

总结：**先大纲后排版，逐页迭代，不推倒重做。**

## 四、深度研究与资讯简报

四个核心环节：
1. **任务编排**：说清目标结果、约束条件、输出格式、完成标准，AI **自主拆解**步骤。
2. **多源整合**：联网多渠道搜索 + 本地文件**交叉验证**。
3. **报告输出**：核心结论、数据图表、引用来源、行动建议。
4. **每日资讯简报**：固化为日常简报（天气、行业动态、任务摘要），一次配置长期受益。

使用差异：单次 → 前三步；高频复用 → 第四步固化简报。
### 研究任务自驱四要素
1. **说清目标**：目标、结果、完成标准（AI 按**目标驱动**，非步骤驱动）。
2. **限定边界**：时间范围、数据来源、文件格式；无边界则无限发散。
3. **指定输出**：Markdown 或表格、是否附来源链接。
4. **自检后交付**：要求输出前自检（结构完整、信息无重复）。

## 五、四个高频提效技巧（全场景通用）

1. **清晰表达**：做什么 + 有什么 + 怎么样。
2. **小步快跑**：大任务拆小步骤，每步确认方向再继续。
3. **给身份**：专家中心「召唤专家」，保留系统提示词，**首句重申专家身份**。
4. **给样例**：一个满意样本胜过十句描述。

底层逻辑：**AI 不是不会做，是不知道你要什么。**

## 六、案例串联：季度经营分析汇报

背景：市场部周五向管理层做 Q2 复盘，手头 **90 行 Q2 销售明细 Excel**（脱敏模拟数据）。

1. **数据分析**：拖入 Excel，「分析 Q2 各产品线营收趋势与异常值，生成趋势图表」；本步输出是下一步输入。
2. **文档生成**：「生成 Q2 经营分析报告，面向管理层，含**执行摘要、数据洞察、策略建议**三部分」。
3. **PPT 制作**：「生成十页管理层汇报 PPT，深蓝商务风，配演讲稿和 Q&A 要点」。

核心启示：**数据分析 → 文档生成 → PPT 制作**标准流水线；上一步产出自动成为下一步输入，不切工具、不复制粘贴；**两小时任务十分钟交付**；真实场景须先脱敏。

## 易混点速记

| 易混点 | 文档/PPT 场景 | 深度研究场景 |
|---|---|---|
| 任务描述四要素 | 目标+对象+结构+迭代 | 目标+边界+输出+自检 |
| 单次 vs 复用 | 单次对话；复用 Skill 模板 | 单次前三步；复用固化简报 |

| 概念 | 关键内容 |
|---|---|
| 数据分析四步 | 导入→分析→出图→解读 |
| PPT 四步 | 需求到大纲→自动生成→迭代美化→演示辅助 |
| 深度研究四环节 | 任务编排→多源整合→报告输出→每日简报 |
| 纪要五字段 | 议题、结论、待办、责任人、截止时间 |
| 提效四技巧 | 清晰表达、小步快跑、给身份、给样例 |
| 脱敏对象 | 姓名、身份证号、手机号、银行卡号、企业机密数据 |
| 案例报告三部分 | 执行摘要、数据洞察、策略建议 |
