# 第1课 考点笔记（产品与基础入门）

## 一、产品概览与定位

### 1. 官方定义
**WorkBuddy 是腾讯推出的全场景职场 AI 智能体工作台。** 三个关键词：
- **工作台**：安装在本地操作系统上的客户端软件，可在用户授权下直接对接本地文件系统、文件夹和本地资料（与云端 AI 助手最底层的架构差异）。
- **智能体（Agent）**：具备**自主规划、自主决策、自主执行**能力的 AI 产品。业务岗一句话记忆：它不仅会聊，还会动手。
- **全场景职场**：不挑岗位、不挑行业（产品、运营、销售、HR、财务、市场、研发均可）。

**价值主张**：一人指挥，全行业专家执行，从策略到交付一站搞定。

### 2. 四大核心能力（必背，顺序完整）
1. **理解自然语言**：一句话下达任务，体验是"说话就行"。
2. **自主规划执行**：你给目标，它给路径并自己走完（Agent 与对话机器人最本质的边界：拥有自己的行动链条）。
3. **多任务处理**：多个任务一次下达、并行处理。
4. **本地文件操作**：区别于云端 AI 工具的关键，自己进文件夹，自己读、写、存；实现从"AI 帮你想"到"AI 帮你做"。

### 3. 与传统对话式 AI 的四点差异
**行动力、文件操作、任务复杂度、输出形态**（输出形态关键词："可验收的结果"，即可直接使用的文件、报表、PPT）。

### 4. 目标用户画像
核心定位五关键词：**自然语言交互、简单易用、本地化、数据安全、移动便捷**。

四类用户：
1. **移动办公者**：地点不固定，要求移动便捷、简单易用（手机指挥电脑上的 WorkBuddy）。
2. **创意产出者**：文案/设计/策划，创意素材不上公共云端，切中本地化与数据安全。
3. **数据分析者**：零门槛数据处理，自然语言描述需求，不写代码。
4. **一人公司创业者**：1~3 人团队、身兼数职，匹配多任务处理与自主规划执行。

共同点：零编程基础可用，追求安全、简单、随时随地。

## 二、桌面端安装与环境配置

### 1. 系统要求
- Windows：**Windows 10 及以上**（Win7/8/8.1 均不支持）。
- Mac：**macOS 12（Monterey）及以上**。
- 查版本：Windows 按 `Win+R` 输入 `winver`；Mac 点苹果图标 →"关于本机"。

### 2. Windows 安装
- 唯一官方网站：**www.workbuddy.cn** →"下载 WorkBuddy"。
- 安装向导：同意协议 → 确认安装路径（默认 C 盘，可"浏览"改盘）→ 开始菜单文件夹 → 勾选创建桌面快捷方式 → 安装 → 完成。

### 3. Mac 安装（关键区别：版本选择）
- 判断芯片：苹果图标 →"关于本机"→ 看"芯片"栏。
- **M 系列芯片选 Mac ARM64；Intel 芯片选 Mac X64**（装错跑不起来）。
- 安装包格式：`.DMG` 磁盘映像（Mac 软件分发标准格式）。
- 三步：双击 .DMG → 把 WorkBuddy 图标**拖入 Applications 文件夹**（拖进去这一步就是安装）→ 推出挂载磁盘、删除 .DMG。

### 4. 首次启动与登录
- Mac 启动两种方式：启动台点图标；或 `Command + 空格` 聚焦搜索输入 WorkBuddy 回车（更快）。
- 登录流程：点"登录"→ 自动调起默认浏览器 → 勾选服务条款和隐私协议（注意隐私协议中本地文件读取部分）→ 选登录方式（**微信扫码登录、手机号登录**等）→ 自动跳回客户端。

### 5. 安装验证（三步自检）
1. **确认登录状态**：左下角头像区显示微信昵称和头像。
2. **发送测试消息**：如"你好，请介绍一下你自己"，几秒内收到回复即链路通。
3. **检查版本号**：右上角查看，非最新则点 WorkBuddy 菜单"检查更新"。

## 三、主界面与核心功能模块

### 1. 新建任务栏：七项配置 + 语音输入
1. **添加文件**：挂载本地文档/表格/PDF 或腾讯文档、资料库文件。
2. **切换对话模式**：Craft、Ask、Plan 三种工作模式（决定执行权限与交互方式）。
3. **选择模型**：模型是 WorkBuddy 的大脑。
4. **配置技能（Skill）**：工具能力扩展（会查表、画图、调 API）。
5. **连接器**：与外部服务对接，数据互通与能力扩展。
6. **选择工作空间**：指定任务在哪个项目文件夹里干活。
7. **配置权限控制**：默认权限 / 完全访问权限；日常保持默认，仅可恢复、可隔离任务短时切完全访问。

最右侧**麦克风**：按住说话即语音输入。下达的不是一句话，而是"带配置的任务包"。

### 2. 任务列表（左半）
- 任务卡片三要素：**任务标题、当前状态、最近更新时间**。
- **六种状态（必背）**：进行中（还在执行）、已完成（跑完）、失败（中途出问题）、待处理（卡在某一步等你补充输入）、规划中（正在拆解需求还没动手）、已归档（你主动收纳）。
- 顶部工具：**搜索框**（按标题）、**筛选按钮**（按状态或日期）。
- 任务操作：新建、置顶、打开文件夹、重命名、保存到工作空间、分享、删除、归档。
- **保存到工作空间**：沉淀为工作空间后可开多个 Agent 同时协作、随时用 ID 打开；从一次性对话走向长期项目的关键。工作空间三动作：新建、打开文件夹、从列表中移除。
- **继续任务**：已完成/失败/中断的任务都可重新点进去续聊；**上下文不丢，对话可续**。

### 3. 结果区（右半）四个标签页
1. **产物**：交付成品集中展示（Word、Markdown、PDF、Excel、CSV、PPT、分析报告），可直接预览和分享。
2. **工作空间文件**：看当前工作空间里有什么（文件树 + 内容区），检查文件是否写到正确位置。
3. **变更**：列出本次任务改了哪些文件、改了什么，接受结果前先看（适合代码开发和配置调整场景）。
4. **浏览器**：内置浏览器，直接看网页、原型、本地 Web 应用运行效果。

### 4. 专家中心
- **专家**：模型 + 人设 + 方法论 + 工具打包的 AI 角色，针对具体岗位深度打磨（如用户研究专家）。
- **专家团**：有团长、有分工、有协作的多 Agent 团队；团长自动拆解、分配给团员并行执行、整合交付。
- 操作流程三步：左侧边栏点"专家"进入 → 选中后点"召唤"（或选示例提示词）→ 执行任务等结果。专家团卡片比专家卡片多一项**团队成员名单**。
- 提醒：专家团积分消耗通常是单个专家的数倍；AI 内容仅供参考，不能替代专业判断。

#### Skill、专家、专家团辨析（必考）
- **Skill 是能力**：让 AI 能做某件事的工具。
- **专家是能力加经验**：懂领域、有方法论的 AI 顾问。
- **专家团是多位专家加协作流程**：自拆任务、并行干活、整合交付的团队。
- 选择：要工具能力配 Skill；单点问题请专家；复杂多角色任务请专家团。

### 5. 系统设置（头像 → 设置 → 系统设置）
- **简洁模式**：默认开启，折叠工具调用等过程信息；想看每步在干嘛就关掉。
- **非高风险自动安装**：上传 Skill 时做安全检测，非高风险自动装，**高风险始终需手动确认**（安全底线）。
- **锁屏远程**：开启后电脑不休眠，适合手机远程操控、自动化任务执行两类场景。
- **默认工作空间存储路径**：管理新建任务和工作空间的存储位置。

### 6. 模型配置
- 内置模型：Auto、混元、GLM、MiniMax、Kimi、DeepSeek 等；**自动模式**按任务自动选模型，新手最稳。
- 自定义模型四类接入方式：
  1. **提供商接入**：选内置提供商，URL/模型列表/能力标记自动填充，只需补 API Key（最省事）。两种鉴权计费方式：
     - **TokenPlan**：按 token 用量计费，腾讯云账号体系鉴权计费，支持混元、MiniMax、Kimi、GLM 等；
     - **CodingPlan**：AI Coding 场景专属订阅套餐，支持腾讯云、智谱、Kimi 的 CodingPlan。
  2. **自定义 API**：内置主流厂商预设入口，一键接入。
  3. **本地部署（Ollama）**：开源本地大模型运行工具，监听 **11434 端口**，兼容 OpenAI 协议。适合：数据隐私/内网合规、零成本（不耗 token）、离线可用。
  4. **纯自定义模型（Custom）**：手动填 URL、API Key、模型名。
- **自定义协议**（高级配置，默认关闭）：模型走非标准 URL 路径（经网关/代理封装）时打开，直接按所填 URL 发请求，跳过路径校验和自动补全。
- 一句话：**内置模型负责开箱即用，自定义模型负责按需扩展。**

### 7. 数据管理（头像 → 设置 → 数据管理）
- **我分享的文件**：可复制链接、下载、取消分享；取消后链接立即失效。
- **已归档任务**：支持删除，也支持取消归档放回任务列表。**归档不是删除**，是隐藏显示、可找回。

### 8. 记忆管理
- **生成对话记忆**：默认开启，从对话提取上下文写成记忆条目供未来调用；仅本人可见；每晚重新生成，可查看、编辑，也可对话式说"请记住这件事/请忘掉这件事"。
- **导入记忆**：跨产品迁移通道——复制示例提示词到其他 AI 让其总结使用习惯，结果粘贴回来点"添加到记忆"。

## 四、三种工作模式 Ask / Craft / Plan

### 1. 划分依据
两个维度：**执行权限**和**交互方式**。
- 三种交互：你说我答（纯对话）；你说我做（直接交付）；你说、我先想清楚、你审阅过我再做（多一步确认）。

| 模式 | 口号 | 含义 |
|------|------|------|
| Ask | Talk only, hands off | 只张嘴，不动手 |
| Craft | You say, I do | 你说了算，我直接干 |
| Plan | Think first, do second | 先想清楚，再去做 |

### 2. Ask 模式
- 核心特征：**仅问答与信息查看，不修改文件**（最强承诺：不改电脑里任何一个字节，最多读、总结、解释）。
- 三类场景：**了解内容**（陌生项目文档归类摘要）、**确认需求**（把模糊想法聊清楚）、**安全审视**（合同/生产配置/客户资料只了解不动手）。
- 口诀：拿不准要不要动手的时候，先 Ask。

### 3. Craft 模式
- 核心特征：**直接执行任务并修改文件**（动手能力最强、动手最快，读写建文件自己决定）。
- 三类场景：**文档生成**（目标清楚、产物明确）、**表格处理**（确定性操作）、**文件整理**（批量、机械、重复）。
- 本质：一句话下单，等成品交付；牺牲中间过程可控性，换端到端效率。使用前提：对任务边界和产物形态足够清楚。

### 4. Plan 模式
- 核心特征：**先生成执行计划，确认后再操作**（Ask 与 Craft 之间的中间态；计划可修改、重新规划再确认）。
- 三类场景：**多步骤任务**（步骤多、互相依赖）、**需要审阅改动范围的任务**（做错回滚成本高）、**需要讨论协作的任务**（计划本身是可共享的任务说明书）。
- 价值：**把出错风险前置成审阅成本**——多花一分钟看计划，少花一小时回滚。

## 易混点速记

| 易混点 | A | B | 区分关键 |
|--------|---|---|----------|
| 三种模式权限 | Ask 不修改文件 | Craft 直接修改文件 | Plan 介于两者之间：先出计划、确认后才动手 |
| 三种模式口号 | Ask：Talk only, hands off | Craft：You say, I do | Plan：Think first, do second |
| 待处理 vs 规划中 | 待处理：已动手、卡住等你补充输入 | 规划中：正在拆解需求、还没真正动手 | 一个"等输入"，一个"没开工" |
| 归档 vs 删除 | 归档：隐藏显示、可取消归档找回 | 删除：彻底移除 | 归档 ≠ 删除 |
| Skill vs 专家 vs 专家团 | Skill：能力（工具） | 专家：能力+经验（顾问） | 专家团：多位专家+协作流程（团队） |
| Mac 芯片版本 | M 系列 → Mac ARM64 | Intel → Mac X64 | 装错跑不起来 |
| TokenPlan vs CodingPlan | TokenPlan：按 token 用量计费，通用模型 | CodingPlan：AI Coding 场景订阅套餐 | 一个是计量计费，一个是场景套餐 |
| 提供商接入 vs 纯自定义 | 提供商接入：URL/模型列表自动填充，只补 API Key | 纯自定义（Custom）：URL、Key、模型名全手填 | 有无预设自动填充 |
| 产物 vs 工作空间文件 | 产物：本次任务生成了什么 | 工作空间文件：整个工作空间里有什么 | 一个是"产出"，一个是"存量" |
| 简洁模式默认状态 | 默认开启（折叠过程信息） | 想看每步细节需手动关闭 | 关闭后才看到工具调用过程 |
| 自定义协议开关 | 默认关闭：标准路径+自动补全 | 打开：按所填 URL 直发、跳过校验补全 | 仅在非标准 URL 路径（网关/代理）时打开 |
