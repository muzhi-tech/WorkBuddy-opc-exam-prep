# 第7课 考点笔记（资料库）

## 一、资料库的定义与定位

- 一句话定义：**资料库 = 不用手动下载、不用手动上传、不用频繁切应用的 AI 文档工作台**。
- 核心工作流三步（「取用存闭环」）：
  1. **取资料**：搜索即找到，点击即预览，选中文件点「添加到任务」交给 AI。
  2. **AI 加工**：输入框描述任务（总结要点、提取表格数据、改写商务语气等）。
  3. **存回沉淀**：产物面板 → 「上传到云端」→ 选存储位置；在对应平台「我的文档」中永久保存、可追溯。
- 核心价值：不用下载、不用上传、不用切应用，全在 WorkBuddy 内完成。

## 二、四大核心优势

1. **AI 和文档深度集成**：搜索即找到，点击即预览，一键即开工，不需先下载再处理。
2. **产物一键存回**：取用存完整闭环，AI 生成的报告、总结可直接存回知识库。
3. **本地文件也支持**：Word、Excel、PPT、PDF 本地文件都能勾选添加到任务，不只限在线文档。
4. **账号灵活换绑**：可解除绑定，可换绑其他账号。

## 三、三大知识平台

已接入三大知识平台（另有卡片留给未来扩展，生态持续丰富中）。

| 平台 | 定位 | 核心能力 | 适用场景 |
|------|------|----------|----------|
| 腾讯文档 | 在线协作文档平台 | 支持 Word/Excel/PPT/PDF，实时协作编辑与版本管理；**最早接入**的平台 | 个人文档 |
| ima 知识库 | 腾讯 AI 驱动的个人知识管理平台 | 智能检索与知识萃取：自动提取关键信息并知识分类 | 深度知识管理的个人用户 |
| 乐享知识库 | 腾讯旗下企业知识社区平台 | 团队文档沉淀、知识问答、经验分享，企业级知识资产体系化管理 | 企业团队 |

- 选择口诀：**个人文档用腾讯文档，知识管理用 ima，团队协作用乐享**，三者互补。

## 四、两种搜索方式

| 维度 | 语义搜索 | 关键词搜索 |
|------|----------|------------|
| 入口 | 新建任务，自然语言描述需求 | 资料库主页右上方搜索框输入关键词回车 |
| 示例 | 「上周的会议纪要」「小王写的项目方案」 | 输入「黑客松」 |
| 匹配方式 | 不依赖精确关键词，模糊描述也能匹配 | 精确匹配，速度快 |
| 适用场景 | 不记得文件名、只记得大概内容 | 知道文件名或作者 |
| 检索维度 | — | 两种可切换：**文档标题** + **文档所有者** |

- 组合使用：**先语义搜索缩小范围，再关键词精准锁定**；找到后可直接在任务中引用。

## 五、连接腾讯文档：四步授权

流程：选择 → 授权 → 扫码 → 完成，全程不到一分钟。

1. **选择更多**：左侧边栏点「更多」→ 资料库入口 → 点「腾讯文档」卡片。
2. **立即前往授权**：触发 **OAuth 授权流程**，展示两类核心权限：
   - 第一类：**读取文档内容**（各类型文件、文件夹及具体内容）；
   - 第二类：**编辑与管理文件**（查看、编辑、创建及管理）。
3. **扫码登录**：支持**微信扫码**或 **QQ 扫码**，选绑定了腾讯文档的账号；浏览器已登录账号会自动出现可直接选择；扫码后手机上确认授权。
4. **完成连接**：可能有附加授权确认，点同意即完成；资料库页面可见文件列表；左上角可新建或上传多种格式文件。

### 授权安全三条铁律（口诀：按需开、专用号、勤巡检）

1. **按需授权**：最小权限原则，只开业务真正需要的；权限给多了不是方便，是风险。
2. **用专用账号**：不绑个人主账号，建独立服务账号，出问题好隔离、好追溯。
3. **定期巡检失效连接**：OAuth 连接有生命周期（账号离职、权限变更、token 过期），及时清理失效连接。

## 六、取用存完整链路操作细节

- **取**：资料库勾选目标文件 → 「添加到任务」；本地 Word/Excel/PPT/PDF 也可勾选。
- **加工**：输入提示词（如「提取文档大纲并生成报告」）；完成后在右侧产物面板查看，点击可预览。
- **存**：产物面板 → 「上传到云端」→ 选腾讯文档 / ima / 乐享 → 系统提示已保存 → 对应平台「我的文档」中查看。

## 七、解除绑定

1. 进入资料库，点击对应的已绑定文档。
2. 右上角点「解除绑定」，确认即完成。
3. 解除后**授权立即失效**；重新使用需重新走授权和登录流程。
- 特别注意：**解除绑定只断开连接关系，不会删除任何文件**，数据在原平台完好无损。

## 八、最佳实践（四条关键提醒）

1. **权限最小化**：初次只授权必要权限，按需增补；只做总结先给读取权限，需要写入时再补。
2. **账号专用化**：用工作专用账号连接，避免与个人账号混用。
3. **产物分类沉淀**：存回时按项目命名文件夹（如「项目X2026」），便于检索和团队共享。
4. **定期巡检**：月度检查连接状态，及时处理过期或失效授权。

## 易混点速记

| 易混点 | 关键区分 |
|--------|----------|
| 语义搜索 vs 关键词搜索 | 语义：新建任务、自然语言、不记得文件名时用；关键词：资料库右上搜索框、精确匹配、知道文件名/作者时用 |
| 关键词搜索两个维度 | 文档标题（按文件名） vs 文档所有者（按作者），是关键词搜索内部切换，不是两种搜索方式 |
| 三大平台分工 | 腾讯文档=个人文档（最早接入）；ima=个人知识管理（AI 萃取）；乐享=企业团队知识社区 |
| 解除绑定的后果 | 授权立即失效、需重新授权登录，但**不删除任何文件**，数据在原平台完好 |
| 两类核心权限 | 读取文档内容 vs 编辑与管理文件（查看/编辑/创建/管理） |
| 扫码登录方式 | 微信扫码或 QQ 扫码，选绑定了腾讯文档的账号 |
| 产物存回去哪看 | 对应平台的「我的文档」 |
