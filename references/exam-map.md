## 跨章易混点对照（考试重灾区）

| 易混组 | 关键区别 | 涉及章节 |
|--------|---------|---------|
| Ask / Craft / Plan | Ask 只答不动手、Craft 直接执行、Plan 先规划确认再执行 | 01、02 |
| Skill / 专家 / 专家团 | 技能=工具能力插件；专家=领域角色智能体；专家团=多专家协作 Multi-Agent | 04、09、11 |
| 灵感 / 技能 / 专家 | 新手做同款→灵感；任务明确重复用→技能；领域专业问题→专家 | 06 |
| 连接器 / 技能 / MCP | 连接器解决「拿到外部数据」，技能解决「会做什么事」，MCP 是底层协议 | 04、05 |
| 语义搜索 / 关键词搜索 | 语义按意思找（模糊需求）、关键词按字面找（精确定位），可组合 | 07 |
| 标准推理 / 深度思考（Thinking） | 日常任务用标准省积分；复杂分析用深度思考 | 09 |
| 四种模型接入 | Token Plan / Coding Plan / 自定义 API / Ollama 本地，按成本与数据安全选型 | 09 |
| 归档 / 删除 | 归档可找回、删除不可恢复 | 01、02 |
| 软打断 / 硬打断 | 追问调整用软打断；误改文件等止损用硬打断 | 02 |
| 关闭技能 / 卸载技能 | 关闭可再开、卸载需重装 | 04 |
| 企微两种接入模式 | 按部署条件与运维成本选型（详见第 3 章对比表） | 03 |
