# 第8课 考点笔记（自动化）

## 一、自动化的定义与执行位置

**一句话定义**：配置完成后，WorkBuddy 按设定时间自动执行，结果保存到指定目录。自动化不是提醒你去做，而是直接帮你做完；执行结果自动落到工作空间，生成真正的文件产物，不是推送一句话消息。核心理念：周期性任务自动跑起来，人不在电脑前也能收到结果。

**本地执行（重要考点）**：自动化任务在你的**本地电脑**上执行，不是云端执行。三个含义：① 数据永不离开电脑，隐私更安全；② 可直接操作本地文件，无需上传下载；③ 可用本地环境、安装任何库，执行能力更强。对比：其他 AI 工具的定时任务常需把数据上传云端，存在隐私泄漏风险——本地执行是 WorkBuddy 最大优势之一。

**PPT 四个典型场景**：每日简报（每天 9 点汇总 AI 行业新闻）；周报汇总（每周五自动汇总本周产物，直接生成文档、人只审核）；定时数据整理（每月 1 号整理上月报表）；体检 / 学习计划（到点提醒，个人生活助理）。

## 二、四类高频用法

1. **日报 / 周报**：每日、每周自动汇总，生成结构化报告，到点落地。核心场景。
2. **行业资讯监控**：每日定时抓取 → 按主题汇总 → 推送小程序。适合产品、运营、市场。
3. **定时数据整理**：月度、季度汇总，自动生成 Excel 存回资料库。适合财务、数据分析。
4. **提醒类任务**：体检预约提醒、学习计划追踪、会议前材料准备。

## 三、定时调度机制（RRULE / iCalendar）

客户端内置「定时闹钟」，不依赖外部定时服务。

**两种定时模式**：① **循环任务**：按规则重复执行，规则的专业名词叫 **RRULE**，WorkBuddy 使用标准 **iCalendar 的 RRULE 格式**（即日历文件 .ics 的格式）；② **单次任务**：指定具体时间点执行一次。配置面板会自动生成规则，不需手写。

**RRULE 常用示例**：
- 每天 9 点：`FREQ=DAILY;BYHOUR=9;BYMINUTE=0`
- 每周一 14 点：`FREQ=WEEKLY;BYDAY=MO;BYHOUR=14`
- 每 2 小时：`FREQ=HOURLY;INTERVAL=2`

**执行前提（很重要）**：电脑开机且 WorkBuddy 运行中；网络正常且任务未被禁用；完成后可推送小程序，人不在电脑前也能收到结果。

## 四、自动化 VS 手动

| 维度 | 自动化 | 手动 |
|------|--------|------|
| 适合任务 | 重复性高 + 时间规律 + 格式固定（每日日报、每周周报、每月数据报表） | 一次性、需人工判断、创意性强（头脑风暴、复杂决策、一次性调研报告） |
| 人工干预 | 设定规则后无需人工干预 | 每次都需人工触发和确认 |

**混合模式（最佳实践之一）**：AI 生成初稿（自动）→ 推送小程序 → 人审核确认（手动）→ 满意则持续执行。

**最佳实践**：自动化省每次重复操作的时间，但需一次性设计好 Prompt。**先手动跑通一次确认效果，再转为自动化循环执行**，避免跑出错误结果反复犯错。

## 五、不宜自动化的三类场景

1. **敏感数据外发**：自动化可能自动调用邮箱连接器发邮件、上传文件到云端。提示词含密钥、API token、客户隐私数据等于定时自动外传。涉及密码、密钥、身份证号的任务建议手动执行、人工审核后再发送。
2. **不可逆操作**：删除文件、批量重命名、提交代码到仓库、修改数据库等。脚本出 bug 可能造成不可挽回的损失。原则：先手动跑通确认无误再自动化，首次执行关注历史记录。
3. **对外发送类**：自动群发客户消息、营销邮件。发送对象、内容、频率出错都会被对方收到，没有撤回机会。对外沟通保留人工确认环节。

**权限校验意识**：自动化任务权限等同于已授权的所有连接器和技能（Skill），不因自动化降低，也不额外申请。创建前检查：任务启用了哪些连接器？有没有权限做这件事？

## 六、创建自动化任务：管理页面与八项配置

**管理页面入口**：左侧边栏第五个图标「自动化」。两个核心区域：上方**已安排任务**（所有激活任务，含名称、频率、下次执行时间）；下方**历史执行记录**（每次执行的详情）。右上角「添加」新建任务；「从模板添加」从模板创建。

**八个核心配置项**：
1. **名称**：区分任务，建议「动词 + 对象」，如「每日 AI 新闻」；
2. **工作空间**（可选）：执行目录和文件保存位置，默认即可；
3. **提示词**：做什么、输出什么，最关键的一项，要清晰、可量化、明确输出格式；
4. **模型、技能、专家或专家团、访问权限**：模型默认 Auto 模式（自动选最合适模型）；技能即 Skill（新手理解为给 AI 装专业技能模块；开发者本质是系统提示词 + 工具调用的组合，可自定义）；专家/专家团按预设角色和知识库执行；访问权限允许 AI 在无人值守任务中自动执行操作，可能涉及敏感数据或文件修改，仅在敏感任务时使用，可随时恢复默认权限；
5. **连接器**（可选）：选已授权连接器，勾选后任务执行时免确认直接使用；
6. **执行频率**：三种模式——**周期**（按天/周/月重复）、**按间隔**（每隔 N 小时/N 分钟）、**单次**（指定时间点执行一次）；
7. **生效 / 过期日期区间**（可选）：留空表示一直有效，设区间适合临时或试用期任务；
8. **推送到 WorkBuddy 微信小程序**（可选）：建议开启。

**提示词最佳实践（5 条）**：① 明确输出格式（Markdown、表格、JSON 等）；② 限定字数、条数（如「500 字内」「不超过 5 条」）；③ 给出输入 / 输出示例；④ 指定异常处理（如「无数据时输出『今日无更新』」，避免编造内容）；⑤ 避免开放式问题，越具体越稳定。

**创建与验证流程**：打开管理页面 → 添加任务 → 填八项配置（重点：提示词和执行频率）→ 保存并启用 → **测试运行**：点击任务 →「测试运行」→「查看运行详情」，输出不对就改配置再测。

对比传统定时任务工具（如 Windows 任务计划程序）：只能执行固定脚本，无法处理需要理解力的任务。

## 七、任务模板

模板覆盖工作、学习、生活、娱乐各类场景，开箱即用：
- **工作类**：每日 AI 新闻推送、每周工作周报、会议前准备、面试准备提醒；
- **学习类**：每日五个英语单词、历史上的今天、每日一个为什么；
- **生活类**：体检预约提醒、父母联系提醒；
- **娱乐类**：经典电影推荐、每日儿童睡前故事、可爱萌宠手机壁纸。

选择模板后，名称、提示词、定时规则等自动填充，只需微调细节（如主题、时间）即可启用。与探索模块「一键复刻」思路一致。

## 八、推送到 WorkBuddy 小程序

**推送机制**：本地执行完任务后，通过**加密通道**同步到云端，再推送到 WorkBuddy 微信小程序，手机打开小程序看完整结果，全程加密传输。**使用前提**：需先在助理设置中绑定 WorkBuddy 小程序（第三章机制）。

**四大优势**：① **实时性**：执行完立即收到通知；② **便利性**：通勤、出差路上也能看；③ **安全性**：加密通道传输，企业数据可控；④ **归档性**：小程序内可查看历史推送记录。

## 易混点速记

| 易混点 | 正确结论 |
|--------|----------|
| 自动化在哪执行 | **本地电脑**执行，数据不离开电脑；其他 AI 工具的定时任务常需上传云端 |
| 自动化是提醒还是执行 | **直接帮你做完**并生成文件产物落到工作空间，不是发提醒消息 |
| 循环规则的格式 | **iCalendar 的 RRULE 格式**（.ics 日历文件格式），配置面板自动生成，不用手写 |
| 执行频率三种模式 | 周期 / 按间隔 / 单次，对应定时任务的循环与单次两种模式 |
| 八项配置中可选项 | 工作空间、连接器、生效日期区间、推送小程序为可选；提示词是最关键项 |
| 连接器勾选后效果 | 任务执行时**免确认直接使用**，需已授权 |
| 自动化权限 | 等同于已授权的连接器和技能，不降低、不额外申请 |
| 推送链路 | 本地执行 → 加密通道同步云端 → 推送小程序；前提是已绑定小程序 |
| 哪三类不宜自动化 | 敏感数据外发、不可逆操作、对外发送类 |
| 上线前最佳实践 | 先手动跑通一次确认效果，再转自动化循环执行；配好后用「测试运行」验证 |
