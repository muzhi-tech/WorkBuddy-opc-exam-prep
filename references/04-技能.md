# 第4课 考点笔记（技能）

## 一、技能是什么

- **定义**：技能 = 给 WorkBuddy（AI）配的工具装备，扩展 AI 的能力边界，让 AI 从「只会说」变成「能做事」。
- **三段式流程**：AI 大脑（原生对话能力，通用但不专精）→ 技能装备（教 AI 做专业领域工作，如 PDF、Office、绘图）→ 工作产出（专业、可复用、确定性的结果）。
- AI 最大的短板不是不够聪明，而是「没有手」——能想到但做不了，技能就是给 AI 装上手。

### 技能 vs 普通对话（四维度对比）

| 维度 | 普通对话 | 技能 |
|------|----------|------|
| 能力来源 | 模型训练时学会（聊天、写文章） | 通过技能包定义获得新能力（如操作文件） |
| 一致性 | 每次回答可能不同 | 严格按步骤执行，输出稳定可预期 |
| 可重复性 | 重问一次结果可能变 | 每次同步骤执行，结果基本一致 |
| 适用场景 | 问问题、头脑风暴、获取建议 | 执行具体任务、重复性工作、精确输出 |

- 核心区别：**普通对话是「说」，技能是「做」**。

### 概念速记（四关键词）

1. **能力扩展**：给 AI 配的工具装备。
2. **差异化**：比普通对话更稳定、更可重复、更专业。
3. **生态组成**：WorkBuddy 五大组件之一——技能、连接器、资料库、任务管理、助理配置。
4. **和插件关系**：插件是技能的打包组合，一个插件可包含多个技能。

## 二、Function Calling 机制

技能的底层技术。完整流程 7 步：

1. 用户提问 → 2. AI 判断需不需要调工具 → 3. 如需则选择合适的技能 → 4. 从对话中推理参数 → 5. 调用执行 → 6. 拿到结果 → 7. 整合回复给用户。

三大关键特征：

1. **AI 自主决策**：AI 自己判断是否调用技能，用户无需手动指定。
2. **参数推理**：AI 从对话上下文提取参数。例：「把桌面 report.docx 转 PDF」→ `file_path=report.docx`、`target_format=PDF`。
3. **结果整合**：技能返回结果后，AI 整合进回复并附说明。

## 三、技能与 MCP 的关系（六方面）

| 方面 | 技能 | MCP（连接器） |
|------|------|----------------|
| 定位 | 本地能力包（文档处理、代码生成、数据分析） | 远程协议，连接外部服务（邮箱、数据库、SaaS） |
| 执行环境 | 本机运行，用本机 CPU 和内存 | 通过网络调用远程服务 |
| 安装方式 | 三种：技能市场、URL 链接、命令行 | 主要通过 OAuth 授权接入 |

- **典型协作链路**（做日报）：连接器从 QQ 邮箱拉邮件数据 → 技能在本地汇总生成周报 → 连接器把周报存到腾讯文档。
- **选择原则**：数据在外面用连接器；处理在本地用技能；复杂任务两个一起用。
- 一句话：**技能解决「AI 会做什么」，连接器解决「AI 能拿到什么」**。

## 四、安全沙箱（六层机制）

1. **工作目录隔离**：技能只能在当前工作空间目录内操作，无法访问系统其他文件。
2. **危险操作确认**：删除文件、执行命令等高危操作弹窗询问，确认后才执行。
3. **权限按需**：每个技能只获取完成任务所需的最小权限。
4. **用户可控**：可随时启用、禁用、卸载任何技能，改完立即生效。
5. **来源审核**：技能市场上的技能需经平台审核才能上架。
6. **审计日志**：所有技能调用有记录可追溯。

## 五、技能市场页面

- **左侧：推荐及技能市场**（装备商店）：热门技能，一键安装。
- **右侧：已安装**（装备库）：已装技能，可在对话中直接调用，支持启用、关闭、编辑、卸载。
- **关闭 ≠ 删除**：关闭只是暂时不用，随时可再打开，切换零成本。
- **少即是多**：只开当前需要的 3-5 个技能。启用太多 = 候选太多 = AI 容易选错。
- 推荐区特点：一键安装、系统自动配置、不好用一键关闭/卸载。

## 六、三种安装方式

入口均为技能市场右上角「添加技能」按钮：

1. **上传**：导入本地技能包（ZIP 压缩包或文件夹）。技能包必须包含 `skill.md` 文件，用 YAML 格式声明技能名称和描述。安装第三方 Skill 前留意来源与权限。适合已有现成技能包。
2. **查找**：用自然语言描述需求，AI 在技能库中搜索匹配并自动安装。**最推荐的方式**。
3. **创建**：技能库也没有时，让 AI 从零生成专属技能。流程：提需求 → AI 反问关键问题对齐需求（处理什么类型、输出什么格式、典型场景）→ 生成技能功能清单和结构说明供确认 → 自动安装到已安装列表。这是 WorkBuddy 的**自我进化能力**：你缺什么，AI 就帮你长什么。

## 七、四大日常管理操作

1. **安装**：三种方式（上传本地包、AI 查找、AI 创建）。
2. **启用/关闭**：已安装区点技能卡片右侧三个小点图标，在管理弹窗中切换。关闭后文件仍保留，零成本切换；建议按场景只开 3-5 个最精准的技能，提高 AI 匹配准确率。
3. **搜索**：技能区域右侧搜索框。两种场景：记得名字直接搜（如 PPTX）；记不清名字按功能搜关键词（如「表格」「XLSX」），实时筛选。
4. **卸载**：已安装区选择卸载，单个勾选或批量多选均可，确认后彻底删除。

- **关闭 vs 卸载**：关闭 = 把工具收进抽屉（东西还在）；卸载 = 连抽屉一起扔了（要用得重装）。不确定时优先关闭，安全不后悔。

## 八、十大内置技能（零成本精选，枚举完整）

1. **Agent Browser（浏览器自动化）**：操控浏览器自动执行操作（录制回放、批量填表单、数据采集、自动化测试）。注意网站反爬政策。
2. **办公文档四件套**：处理 PDF、DOCX、PPTX、XLSX 四种办公文件。
3. **Local Whisper**：本地语音转文字，不联网、隐私优先。适合会议录音转纪要、访谈整理、语音备忘。
4. **YT-DLP Downloader**：从视频网站下载视频，搭建素材库。
5. **Web Search**：联网搜索实时信息，弥补大模型知识截止日期短板，避免编造答案。
6. **Obsidian**：笔记库管理，AI 读取笔记库做知识管理、内容关联、笔记整理。
7. **Skill Scanner**：技能安全检测（「技能杀毒软件」），新装技能时做审计看有无风险。
8. **Self Improvement**：自我提升，制定学习计划、养成好习惯。
9. **Find Skills**：技能查找，按需求帮你找合适的技能。
10. **Frontend Design**：前端设计，直接生成 UI 草图，快速出设计稿。

- 全部可在技能市场推荐区一键安装。**考试必考两个**：办公文档四件套、联网搜索（Web Search）。

### 办公文档四件套明细

- **PDF**：提取文字；识别表格转 Excel；扫描件 OCR；拆分/合并页面；自动填写 PDF 表单。
- **DOCX**：生成 Word 文档；整理章节结构、自动生成目录；补充目录页码；处理批注和修订。
- **PPTX**：读取 PPT 转文字稿；逐页总结要点；精简页面（十页压成三页）；按大纲重新制作演示文稿。
- **XLSX**：清洗脏数据（去重复项、空白）；自动补公式；生成汇总报表；多表合并；重新组织数据并导出。

## 九、最佳实践（四建议）

1. **仅启用所需技能**：启用过多的三个副作用——AI 误调用不相关技能；上下文膨胀导致推理变慢；匹配精度下降。
2. **按场景切换**：开关零成本，不强制卸载。
3. **单一职责**：一个技能只做一件事，不做「全能助手」（如灵感记录和日报生成拆成两个）。
4. **触发条件清晰**：技能描述里明确「当用户输入 X 时触发」，避免误触发。

- **好的技能 = 单一职责 + 触发条件清晰 + 输出可验证**。

## 十、本章四大核心收获

1. 技能就是装备：没技能 AI 是参谋，有技能 AI 是执行者。
2. 安装三方式：上传、查找、创建，推荐查找。
3. 启用关闭按需来：只开 3-5 个，关闭不等于删除。
4. 可以造技能：不会编程也能用一句话让 WorkBuddy 创建专属技能（自我进化）。

## 易混点速记

| 易混点 | A 面 | B 面 |
|--------|------|------|
| 普通对话 vs 技能 | 对话是「说」，训练获得，输出不稳定 | 技能是「做」，技能包定义，稳定可重复 |
| 技能 vs MCP/连接器 | 技能本地执行，解决「AI 会做什么」 | MCP 远程调用，解决「AI 能拿到什么」 |
| 技能 vs 插件 | 技能是单个能力 | 插件是技能的打包组合，一个插件含多个技能 |
| 关闭 vs 卸载 | 关闭 = 收进抽屉，文件保留，零成本恢复 | 卸载 = 彻底删除，要用需重装；不确定优先关闭 |
| 查找 vs 创建 | 查找：技能库里搜已有技能（最推荐） | 创建：库里没有时 AI 从零生成，会反问对齐需求 |
| Web Search vs Find Skills | Web Search：联网查实时信息 | Find Skills：在技能库中找技能 |
| Local Whisper 特点 | 本地运行、不联网、隐私优先 | 区别于需联网的语音转文字服务 |
| 启用技能数量 | 建议只开 3-5 个 | 开太多 → AI 候选多、易选错、匹配精度下降 |
